# Contrato do carrinho — versão 0

Estado: histórico, substituído pelo contrato vigente em
[requisitos](../requisitos.md). Não usar em novas implementações.

## Desconto

Na versão 0, o desconto era de 5% em qualquer compra. Uma compra de 100 reais
resultava em 95 reais. Este texto é mantido para consulta histórica.
