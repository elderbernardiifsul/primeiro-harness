## Método

Observe o trecho → preveja a consequência → execute um caso → explique a causa
→ proponha a correção → compare. Uma execução do modelo não demonstra uma lei
geral. Se o agente evitar o erro, investigue como ele identificou o conflito.

## Desafios opcionais, fora das duas horas

- Skill com descrição ampla: comparar “use para qualquer código” com um gatilho
  específico e testar também uma tarefa que não deve ativá-la.
- Memória superada: marcar a decisão antiga como substituída e preservar a vigente.
- Contexto excessivo: comparar leitura de toda a biblioteca com leitura sob demanda,
  registrando arquivos e volume lido; não inferir custo de tokens só pelo tamanho.
- Modelo menor: repetir tarefa em clone separado, com o mesmo pedido e estado inicial.
